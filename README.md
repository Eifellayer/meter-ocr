# EifelLayer RF1

Home-Assistant-App zur Kontrolle des Gaszählerstands am Pipersberg G4 RF1 mit SLFork und lokaler OCR.

Trage nach der Installation unter **Konfiguration** die Adresse deines ESP unter `esp_url` ein. Wenn du von der lokalen App wechselst, stoppe sie vor dem Start der Repository-Version. Beide Apps verwenden dieselben Sensor-IDs in Home Assistant.

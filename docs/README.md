# Bedienungsanleitung

Die bebilderte Anleitung erklärt die stabilen Kernabläufe von AI Meter Reader. Sie wird bei neuen Funktionen oder größeren Änderungen an Einrichtung, Prüfung und Ergebnisanzeige aktualisiert. Kleine Text- oder Bezeichnungsänderungen erfordern keine neue PDF-Ausgabe.

Die PDF und ihre App-nahen Mockups werden mit `build_user_guide.py` erzeugt. Die realen Beispielfotos und eine für die PDF verkleinerte Logo-Kopie liegen unter `images/`; das Montagefoto wurde vor der Verwendung anonymisiert, dabei blieb nur das mechanische Zählwerk sichtbar. EXIF-Metadaten wurden entfernt.

Vor Aufnahme der neuen Fotos wurden die veröffentlichten Bilder in der gesamten lokalen Git-Historie sowie in den aktuellen `main`-, `stable`- und `beta`-Zweigen geprüft. Dort lag zuvor nur das Projektlogo; es enthält keine Zählerdaten, Nummern, Barcodes oder QR-Codes. Details stehen in [IMAGE_PRIVACY_AUDIT.md](IMAGE_PRIVACY_AUDIT.md).
